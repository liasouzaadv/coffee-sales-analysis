# Coffee Sales Analysis ☕📊

Este projeto tem como objetivo realizar a limpeza, preparação e análise
exploratória de dados de vendas de uma cafeteria, utilizando Python no
Google Colab.

##  Objetivos
- Limpar e padronizar dados inconsistentes
- Tratar valores ausentes em colunas numéricas e categóricas
- Realizar análise exploratória para identificar padrões de consumo
- Gerar insights relevantes para tomada de decisão

##  Tecnologias Utilizadas
- Python
- Pandas
- Matplotlib
- Google Colab

##  Principais Análises
- Vendas por item
- Receita total por produto
- Tipo de pedido (in-store vs takeaway)
- Métodos de pagamento
- Distribuição do valor gasto

##  Estrutura do Projeto
- `coffee_sales_analysis.ipynb`: notebook com todo o processo de análise
- `clean_cafe_sales.csv`: dataset tratado e pronto para análise

##  Principais Insights
- Bebidas lideram em volume de vendas, enquanto itens alimentícios apresentam maior contribuição para a receita.
- A maioria dos pedidos ocorre no formato takeaway, indicando preferência por conveniência.
- Métodos de pagamento digitais são predominantes.
- Foram identificadas inconsistências nos registros de dados, apontando oportunidades de melhoria na coleta.
